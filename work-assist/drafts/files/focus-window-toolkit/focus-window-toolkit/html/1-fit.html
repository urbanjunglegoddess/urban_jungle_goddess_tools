Focus Break Left over

The math: sessions run back to back with a break between each one. By default the trailing break is dropped — no point resting when you're walking out the door — so a run of N sessions needs N−1 breaks. Flip the toggle if you'd rather bank the final break. "Left over" is time too short for one more full session; use it or bleed it into the next thing.
