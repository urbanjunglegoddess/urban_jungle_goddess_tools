# Website Platform Field Guide — reference record

Internal scoping tool. Not client-facing as-is — it carries stack flags and the blueprint note.

## What each of the 228 records carries

- What it is (one line)
- Best for — the only part that belongs in client-facing writing
- Cost — band, or a verified figure where the vendor's own pricing page was checked
- Who edits it after launch — Client alone / Client, once trained / You maintain / Developer required
- Exit path — Locked in / Content exports only / Exports to code / You own the code
- Ceiling — what it cannot do, or when the client outgrows it
- Status, hosting type, skill level, categories

Filters: nine categories, plus In your stack · No-code only · Client can run it alone · Client keeps the code · Hide legacy & retired.

## The eight intake questions

1. Who updates this after launch, and how often?
2. Are you selling — physical, digital, or time?
3. Does anyone need to log in? (the line between a website and an application)
4. How many pages today, and in two years?
5. What has to connect to it? (CRM, POS, inventory, booking, accounting)
6. What happens if the site is down for a day?
7. What is the budget after launch, not just to build it?
8. Who owns the domain and the existing accounts?

## Cost-of-ownership bands (at $85/hr, adjust from logged time)

- One-page presence — 10–20 hrs — $850–1,700 — platform $0–240/yr
- Brochure site 5–8 pages — 30–60 hrs — $2,550–5,100 — platform $200–700/yr, care $150–400/mo
- Store, launch catalog — 60–120 hrs — $5,100–10,200 — platform $350–3,600/yr + 2.5–2.9% processing
- Custom app or portal — 120+ hrs — $10,200+ — Command Core rate $110, retainer required

Three costs clients never budget: content, maintenance, and switching later. Price the exit before they buy the entrance.
